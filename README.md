# thermo-solver

Energy and entropy problems (Hebrew, 12th grade, 5 units), solved step by step: the question on the side, one short card per step, every number shown with where it came from.

**Open it:** https://jhoni409.github.io/thermo-solver/

- Keys: → / Space / Enter next, ← back, R restart, A autoplay, W why. Phone: swipe.
- אוסף שאלות: the library. ⋯ → ✎ type your own problem.

```
npm install
npm run dev        # local
npm test           # every library answer, exact arithmetic
npm run build
npm run screens    # Playwright screenshots of every step → screens/
npm run checks     # measured bidi order, idle animation, reduced motion (needs `npx vite preview --port 4179`)
```

Spec: `CLAUDE.md` (rules), `BRIEF.md` (spec), `PROBLEMS.md` (test answers).
